## Cara Menjalankan Aplikasi

1. **Prasyarat:** Pastikan Flutter SDK telah terpasang dan terkonfigurasi dengan baik.
2. **Buka Direktori Proyek:**
   ```bash
   cd tabungku_layout
   ```
3. **Mengambil Dependensi:**
   ```bash
   flutter pub get
   ```
4. **Menjalankan Pengujian Widget:**
   ```bash
   flutter test
   ```
5. **Menjalankan Aplikasi:**
   ```bash
   flutter run
   ```
